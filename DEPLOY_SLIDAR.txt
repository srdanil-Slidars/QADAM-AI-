1. ЛОКАЛЬНЫЙ ЗАПУСК В VS CODE

python -m pip install -r requirements.txt
python app.py

Открой http://127.0.0.1:5000/.
Если сервер уже работает, сначала останови его через Ctrl+C.

2. ПОЛУЧЕНИЕ ОБНОВЛЕНИЯ НА PYTHONANYWHERE, КОГДА БУДЕШЬ ГОТОВ

Консоль: https://www.pythonanywhere.com/user/Slidar/consoles/
Выбери Bash и выполни по очереди:

cd ~/qadam
git fetch origin
git switch --track origin/codex/qadam-v2
source .venv/bin/activate
pip install -r requirements.txt
python backup_database.py
python -m unittest discover -s tests -v

Если ветка codex/qadam-v2 уже создана локально, вместо git switch --track ...:

git switch codex/qadam-v2
git pull --ff-only origin codex/qadam-v2

Если Git сообщает о локальных изменениях, остановись и пришли сообщение.
Не используй reset --hard. Локальную базу и instance/session.key не удаляй.

Открой /var/www/slidar_pythonanywhere_com_wsgi.py.
Сохрани прежнее содержимое у себя для возврата и замени его на:

import os
import sys

os.environ['QADAM_COOKIE_SECURE'] = '1'
project_path = '/home/Slidar/qadam'
if project_path not in sys.path:
    sys.path.insert(0, project_path)

Нажми Save. Не запускай python app.py в консоли хостинга.

6. ПРОВЕРКА ПОСЛЕ ОБНОВЛЕНИЯ

- Открывается новая стартовая страница и переключаются обе темы.
- Значок человека открывает профиль, вход и регистрацию.
- Создай тестовый аккаунт куратора. В меню Ещё появится Кабинет куратора.
- Скопируй код группы, выйди и создай тестовый аккаунт студента.
- В разделе Поддержка присоединись по коду и отправь тестовое обращение.
- Снова войди куратором и ответь на обращение.
- В чате студента проверь: «Добавь в план: Подготовить вопросы к семинару».
- Добавь материал университета в кабинете куратора и задай вопрос по нему от студента.

7. ЧТО ВКЛЮЧЕНО И КАКИЕ ЕСТЬ ГРАНИЦЫ

Веса встроенной TopicNet лежат в models/topic-model.json. API-ключи не нужны.
Это небольшая обученная нейросеть для выбора темы, а не универсальная языковая модель.
Ответы основаны на материалах, действия с задачами выполняются по прямой команде.
Проверка на 20 отложенных синтетических примерах: 13 правильных ответов (65%).
Эти данные не доказывают качество на реальных студентах и не являются клинической проверкой.
Перед пилотом нужны экспертная проверка, улучшение набора данных и новая оценка модели.
Не используй AI как психологическую диагностику или экстренную службу.

Вход по почте и паролю работает, но подтверждение почты и восстановление пароля
по email пока не подключены. Отдельного кабинета психолога и уведомлений по email нет.
Психолог подключается через контакты и маршрут помощи, которые задаёт университет.
У одного куратора пока одна группа. Обращения обновляются при открытии раздела
или по кнопке Обновить. Автоматических сигналов риска и решений о студентах нет.

База сохраняется на сервере. Пароли хешируются, cookie сессии подписывается.
instance/session.key создаётся автоматически и должен сохраняться между обновлениями.
Куратор не получает AI-переписку и личные заметки. Показ последних оценок состояния
студент включает отдельным согласием и может отозвать.

Для демонстрации используй вымышленные данные.
