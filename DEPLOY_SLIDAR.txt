7. ЧТО ВКЛЮЧЕНО И КАКИЕ ЕСТЬ ГРАНИЦЫ

Диалог локально использует Qwen3-4B. Её нельзя запускать на бесплатном PythonAnywhere.
Для чата на хостинге нужен Gemini API (аккаунт и ключ создаёт владелец):
https://aistudio.google.com/api-keys
Ключ не отправляй в чат и не сохраняй в GitHub.
После обновления кода в Bash выполни:

cd ~/qadam
source .venv/bin/activate
python configure_ai.py

Вставь Gemini API key в скрытый запрос (символы не отображаются).
Для модели нажми Enter или введи доступную в аккаунте модель.
Команда отправит только вымышленный тест Google, проверит реальный ответ,
и только при успехе сохранит ключ в закрытом instance/ai.json.
При ошибке текущие настройки не меняются. Ключ не попадёт в историю Bash.
Проверить существующее подключение: python configure_ai.py --check.
После Connection OK нажми Reload во вкладке Web.
В чате включи согласие на облачную обработку.

На PythonAnywhere разрешён домен googleapis.com; квоты и доступность Gemini
зависят от аккаунта и региона. Без настройки чат покажет понятную ошибку,
остальные функции продолжат работать. Для облачного чата студент включает
согласие в интерфейсе. Бесплатность без ограничений не обещается.

ИИ предлагает изменения, но выполняет их сервер после отдельного подтверждения.
Это не собственная модель с нуля: используется открытая Qwen или API Google.
Сам код и архитектуру приложения ИИ не изменяет.

Вход по почте и паролю работает, но подтверждение почты и восстановление пароля
по email пока не подключены. Отдельного кабинета психолога и уведомлений по email нет.
Психолог подключается через контакты и маршрут помощи, которые задаёт университет.
У одного куратора пока одна группа. Обращения обновляются при открытии раздела
или по кнопке Обновить. Автоматических сигналов риска и решений о студентах нет.

База сохраняется на сервере. Пароли хешируются, cookie сессии подписывается.
instance/session.key создаётся автоматически и должен сохраняться между обновлениями.
Куратор не получает AI-переписку и личные заметки. Показ последних оценок состояния
студент включает отдельным согласием и может отозвать.

Для демонстрации используй вымышленные данные.

Официальные инструкции:

SQL-БАЗА

Используется SQLite, файл /home/Slidar/qadam/qadam.sqlite3.
Это SQL-база, отдельный MySQL-сервер для текущей версии не требуется.
Таблицы создаются автоматически, база не публикуется в Git и /static/.
Хранятся аккаунты (хеши паролей), профили, отметки, задачи, чат, группы,
материалы, обращения, ответы и журнал подтверждённых действий ИИ.
Перед каждым обновлением: python backup_database.py.
Не удаляй файл базы и instance/session.key при обновлении.

ОБНОВЛЕНИЕ ЯЗЫКОВ И ФОРМ

В верхней панели — RU / ҚАЗ / EN. Русский — по умолчанию.
Выбор языка сохраняется в браузере и профиле; ответ ИИ запрашивается на нём же.
Личные сообщения, имена и материалы университета автоматически не переводятся.
Окна закрываются крестиком либо после успешного сохранения, не по фону/Escape.
Незавершённые формы сохраняются в памяти вкладки до перезагрузки страницы.
Пароль регистрации не сохраняется в localStorage.
