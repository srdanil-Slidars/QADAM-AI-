# Qadam AI — веб-прототип

Веб-приложение на Flask и SQLite. Python 3.10+.

## Запуск в VS Code на Windows

Открой эту папку в VS Code, затем выполни в терминале:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe setup_local_ai.py
.\.venv\Scripts\python.exe run_local.py
```

Открой http://127.0.0.1:5000. Для остановки нажми Ctrl+C в терминале.
Первичная установка модели: `python setup_local_ai.py`, затем `python run_local.py`.

## Функции

- Стартовая страница с авторским баннером и коротким объяснением проекта.
- Верхняя навигация: Главная, Мой день, План, AI-помощник и дополнительные разделы в меню Ещё.
- Светлая и тёмная тема с сохранением выбора.
- Профиль, название университета и группа.
- Настроение, стресс и заметка: одна обновляемая запись на день.
- Добавление задач, отметка выполнения и прогресс.
- Диалоговый AI: Qwen3 локально, история разговора и подтверждаемые действия.
- График последних семи отметок и история записей.
- Материалы, личные черновики и обращения с ответами куратора.
- Адаптивный интерфейс для телефона и компьютера.
- Фирменный курсор на компьютере, обычный ввод текста в формах.

## Локальная версия дизайна

Новый дизайн использует фиолетовые градиенты с белой или почти чёрной основой.
После запуска главная страница открывается по адресу `/`, рабочее пространство — `/#dashboard`.
Профиль открывается кнопкой с человеком справа сверху, тема — соседней кнопкой.
На телефоне навигация раскрывается кнопкой меню. Движение интерфейса учитывает
системную настройку уменьшения анимации, управление с клавиатуры сохраняется.

Баннер хранится в `static/assets/qadam-hero.png` (1672 × 941, исходный размер генерации).
Изображение создано встроенным ImageGen. Описание генерации — `design/hero-generation.json`.
Новый дизайн предназначен для локального тестирования. Публикация выполняется отдельно.

## Границы прототипа

Языковая модель не заменяет психолога и может ошибаться.
Подтверждение email, восстановление пароля по почте, кабинет психолога и почтовые
уведомления пока не реализованы. Один куратор работает с одной группой.

База `qadam.sqlite3` создаётся автоматически. Данные сохраняются между запусками.
У каждого браузера отдельный профиль: настройки, задачи, отметки, чат и черновики.
Случайный идентификатор хранится в HttpOnly cookie (Secure при HTTPS).
После очистки cookie доступ к прежнему профилю теряется. На общем компьютере
один браузер означает один профиль. Гостевой профиль можно привязать к аккаунту по почте и паролю.
После входа данные доступны с другого устройства. Для демонстрации используй вымышленные данные.

После обновления старые общие таблицы сохраняются в базе, но приложение их
больше не выдаёт посетителям и не переносит в новые профили: их владелец неизвестен.

## Аккаунты и куратор

Значок профиля открывает регистрацию и вход. Куратор создаёт свою группу,
приглашает студентов кодом и добавляет материалы университета. Студент
подтверждает вступление и отдельно выбирает, показывать ли последние оценки
состояния. Чат и личные заметки кураторам не передаются. Обращения и ответы
доступны только студенту и его куратору. Кнопка Обновить получает новые обращения.

## Диалоговый ИИ

Основной помощник — Qwen3-4B (Q4_K_M), готовая языковая модель Qwen под Apache 2.0.
Это интеграция открытой модели, а не собственная модель, обученная с нуля.
Она генерирует ответы, получает последние 8 реплик, личные задачи и доступные материалы группы.
Для установки на Windows: `python setup_local_ai.py` (около 2,5 ГБ), затем `python run_local.py`.
Модель уже установлена на текущем компьютере. Веса и runtime не попадают в Git.
Запуск использует Vulkan и видеокарту, сервер модели слушает только 127.0.0.1:8081.
Приложение открывается на http://127.0.0.1:5000. Остановка — Ctrl+C.

Из чата можно предложить задачу, её завершение, черновик, обращение, ответ и статус.
Все изменения требуют отдельного подтверждения. Сервер проверяет права повторно,
не допускает повторного выполнения и хранит журнал в SQL. Доступа к коду,
произвольному SQL и чужим данным у модели нет. Ответы могут содержать ошибки.

На бесплатном PythonAnywhere локальная модель не запускается. Поддержан облачный
Gemini через официальный API: настройка в DEPLOY_SLIDAR.txt. Нужен ключ владельца
аккаунта Google; облачный вариант без ключа не проверен. В чате требуется согласие
на передачу контекста Google. При сбое провайдера приложение сообщает об ошибке,
не подменяет ответ шаблоном. Бесплатные квоты провайдера не гарантируются.

Прежняя маленькая TopicNet сохранена как исследовательский классификатор
(80 синтетических примеров, 13/20 на отложенной проверке). Она не используется
по умолчанию для диалога. `python train_model.py` воспроизводит её обучение.

## Обновление на PythonAnywhere

Точные команды, Web app setup и WSGI находятся в `DEPLOY_SLIDAR.txt`.
Эталон WSGI — `wsgi_pythonanywhere.py`. Публичный сайт не обновляется автоматически.
Перед обновлением выполняй `python backup_database.py`.
`instance/session.key` создаётся автоматически, не публикуется и должен сохраняться
между перезапусками. В production используй HTTPS и `QADAM_COOKIE_SECURE=1`.
Шрифт Manrope загружается из Google Fonts; без интернета используется системный.

## Структура

- `app.py` — точка входа Flask и личные API.
- `qadam/db.py` — схема SQLite.
- `qadam/accounts.py` — аккаунты и сессии.
- `qadam/campus.py` — группы, согласия, материалы и обращения.
- `qadam/assistant.py` — база знаний и действия помощника.
- `qadam/neural.py`, `train_model.py` — обучение и вывод нейросети.
- `templates/index.html` — оболочка приложения.
- `static/style.css` — темы и адаптивная вёрстка.
- `static/app.js` — страницы и взаимодействие с API.
