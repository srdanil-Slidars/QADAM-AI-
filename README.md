# Qadam AI — локальный прототип

Веб-приложение на Flask и SQLite. Python 3.10+.

## Запуск в VS Code на Windows

Открой эту папку в VS Code, затем выполни в терминале:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Открой http://127.0.0.1:5000. Для остановки нажми Ctrl+C в терминале.
Если Flask уже установлен, достаточно `python app.py`.

## Функции

- Светлая и тёмная тема с сохранением выбора.
- Профиль, название университета и группа.
- Настроение, стресс и заметка: одна обновляемая запись на день.
- Добавление задач, отметка выполнения и прогресс.
- Демонстрационный чат с сохранением переписки.
- График последних семи отметок и история записей.
- Три читаемых материала и локальные черновики обращений.
- Адаптивный интерфейс для телефона и компьютера.

## Границы прототипа

Чат работает по правилам, обученная модель и внешние AI API не подключены.
Черновики обращений никому не отправляются. Контакты служб пока не настроены.
Материалы и сценарии требуют экспертной проверки перед пилотом.

База `qadam.sqlite3` создаётся автоматически. Данные сохраняются между запусками.
Это локальное однопользовательское приложение без авторизации и шифрования базы;
для конкурса используй вымышленные данные. Не открывай сервер в публичную сеть.
Шрифт Manrope загружается из Google Fonts; без интернета используется системный.

## Структура

- `app.py` — Flask, API, SQLite, сценарии чата.
- `templates/index.html` — оболочка приложения.
- `static/style.css` — темы и адаптивная вёрстка.
- `static/app.js` — страницы и взаимодействие с API.
